# Official Account UI references

Two original public PNG assets from Vercel's official Account Management documentation were downloaded and pixel-inspected on 2026-11-09. Exact asset URLs, source, hash, dimensions and dates are in [the reference manifest](round-six-account-published-manifest.json). Images are unmodified. Attribution: Vercel; copyright remains with respective owner. These are documentation-published UI examples, not original work or permission to redistribute.

The source page https://vercel.com/docs/accounts identifies these as Authentication settings and account email addresses. It states last updated September 21, 2026; image capture dates and app build IDs are not given. The documentation source directly embeds the original public blob assets. No authenticated page, login, credential, browser session, account change or native desktop interaction was used.

Observed pixels:

- Authentication: a heading and explanation above one Add New group with labeled provider buttons, Passkey and SAML Single Sign-On. This is a configuration-entry state; the crop does not prove the account has no existing login connections.
- Email: two rows with explicit Verified badges, a Primary badge on one row, contextual ellipsis controls, an Add Another action and a footer explaining verification. This provides a configured-account-state comparison, not a verified live authentication outcome.

For Zen Account, these cover identity/status distinction and placing state-specific actions beside their subject. Pending, failure, retry and subscription-management states remain unrepresented. Do not invent their behavior from static images. The source screenshot's example addresses are documentation content, not the user's account.
