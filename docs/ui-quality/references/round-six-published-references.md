## Pixel observations and applicability

1. `t3-pr28842-general-dark.png` (1280×720): floating Settings window with fixed scoped navigation, search, Settings › General breadcrumb and close control. Main content occupies a restrained centered column; 16px-looking section labels sit outside low-contrast row groups. Descriptions sit directly beneath labels; controls share a right edge. Notifications and Sidebar sections visible, Confirmations partly visible. Useful for Zen General hierarchy, row rhythm, label/control alignment and reducing card-in-card nesting. Limitation: lower settings are clipped, disabled vs off/focus/hover behavior cannot be inferred; subtle dark boundaries are not a contrast measurement.
2. `t3-pr28842-general-light.png` (1280×720): matching General viewport and controls. Near-white body, gray nav, faint row separators, dark enabled switches and white disabled/off thumbs. Layout stays stable between themes. Useful for theme parity and visible state differentiation without restyling the entire surface. Limitation: published static image, no keyboard/focus/contrast audit; don't copy faint dividers blindly.
3. `t3-pr28842-providers.png` (1280×720): scoped All projects/environment controls above Providers; left list of Codex, Claude and Replay with identity icons, availability/version and toggles. Right detail column carries selected provider title/version, display name and Runtime rows with inputs. Useful for Zen Models/provider master-detail layout, selected-provider feedback, scope visibility, labels plus supporting status and aligned inputs. Limitation: development fixture includes Replay; bottom launch arguments are clipped. This is not an Account/billing/profile screenshot and does not validate authentication success, credential flows or save feedback.
4. `t3-pr25251-model-picker.png` (784×362): publisher's before/after comparison. After has compact provider icon rail with blue active marker, search, clear check on chosen model, readable one-line model names, limited NEW badge, and Legacy models disclosure/count. Provider names no longer repeat under every model. Useful for model-menu deduplication, selection vs hover distinction, restrained semantic accent. Limitation: cropped comparison with historical model names and a development conversation behind; not a catalog of models supported by Zen or current T3. No interaction tested.
5. `t3-pr25251-details-dark.png` (624×442): publisher's before/after comparison of context/details card. After groups environment/editor/actions, branch/PR with compact Merge action, Changes with semantic addition/deletion counts, and Previous agents with count/disclosure into separated blocks. Useful for Zen context/agent panel information hierarchy, contextual actions and compact metadata rather than undifferentiated rows. Limitation: no agent execution, expansion, empty/error state or token/context behavior shown; Merge is a consequential source-control action and not a generic agent CTA to copy.
