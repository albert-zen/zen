## 净收益与代价

**本组内容和桌面宽度下选择 Q，存在清楚的净收益，但不是全面完成。** 关键收益不是更密，而是消除了不必要的读向切换：P 的“状态”“通过”“下一步”“保留”被拆成竖向字符，读者从名称到说明再到操作时必须重新组合文字；打开资料卡后连 Review 都成为 Re / vie / w。Q 保住这些语义单元，使“状态 → 检查项 → 说明 → 下一步”的路径连贯，行边界也更容易追踪。

Q 关闭资料卡时表格从约 y=120 到 y=601，P 到约 y=726。这段高度收益主要来自短标签不再撑高短内容行，不是压小字号或强行削减行间距，因此有实际阅读价值。Q 打开资料卡后仍能看到完整末行和结束语，P 打开状态末行在输入框后，P 的末行截图则以表头裁切换取尾部可见。这里只描述截图，不认定 P 的末行不可访问，也不认定 Q 的滚动已通过测试。

**代价必须保留：** Q 给状态和下一步更多横向空间，说明栏随之变窄。资料卡打开时，长英文说明由 P 的约四行增加至 Q 的约五行，中文长说明也有更多折行；长标识符两者都被硬换行，Q 并未让它容易逐字符核对。对于大量长段落、较少短状态的表，Q 的优势可能缩小，不能外推到所有表格。P 的较宽说明栏在逐句阅读长内容时确有收益，但本样本不足以抵消短标签被破坏的成本。

两者仍有共同局限：正文偏小、表格没有明显重点行或状态差异化，主视图顶部说明在当前滚动位置被切去一部分；宽侧边栏与大量空闲的右侧资料区同时存在时，正文空间紧张。右栏的 Idle / Hidden 很克制，虽不抢主对话，但短控制仍较细。Q 更像把表格排版修正到可靠基线，而非完成整套产品视觉系统。

## 可据此采纳的结论

采纳 Q 的短标签完整与末行分隔收益；保留对长说明栏宽的进一步检查。后续应以真实长标识符、长中文段落、窄桌面以及更多行数据另做验证，而不是继续以压低表高为目标。本报告仅评估所提供静态视觉，不宣称点击、滚动、选择复制、键盘操作、响应式或可访问性交互已验收。
