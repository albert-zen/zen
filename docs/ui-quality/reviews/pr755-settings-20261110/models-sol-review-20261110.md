## R/S 可观察差异与共同限制

- 两张 light overview 视觉结构几乎一致，可见的是少量行基线/分节纵向位置变化；没有足够证据跨越 0–4 量表的一个档位，保留同分。
- dark overview 与菜单中，S 的“1 model”是下向箭头，模型条位于更低处且供应商卡更高；R 为右向箭头，模型条较靠上。S 的展开指示与可见内容更一致，但截图状态差异不足以断言实现改进或通用优势。
- 两张菜单的搜索框均能看到插入光标和焦点轮廓，模型名均两行并带勾选；无证据支持其中一方键盘可访问性整体更好。
- 候选共同优点是两级导航定位清楚、默认选择与供应商管理分组明确、颜色语义节制；共同问题是小号灰字、长模型名截断、底部 Apply 的意义仅凭像素不确定，以及宽大空白与密集操作行形成反差。
- Linear 的放大设置行、Vercel 的单功能裁切、T3 的紧凑历史选择器分别提供分组、状态色与菜单组织参照，不是等条件竞赛。对参考图给 N/O 的导航不应被拿来作候选胜出的依据。
