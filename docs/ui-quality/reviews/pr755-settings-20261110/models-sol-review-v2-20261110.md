## 本包 R/S 比较与不确定性

本包暗色 overview/menu 的 R/S 均显示下向 disclosure 与可见 fake 行，展开状态匹配。两者整体布局、菜单宽度、选中项换行及输入焦点形态非常接近。可见的是若干细小纵向间距、文字明暗观感差异，未形成足够稳定且重大的证据改变 0–4 档位，因此相同分数不代表逐像素相同或实现相同。light 图也高度接近。

共同优点：默认模型与供应商分区清楚，双级导航定位明确，操作颜色节制，菜单当前项勾选和输入焦点可见。共同限制：长值截断、小号灰辅助文、紧凑行尾操作与宽大下方空白并存；Apply 的真实状态与保存关系未获验证。

三张参考图均有不同任务和尺度：Linear/Vercel 是放大文档裁切，没有完整导航，因此导航 N/O；T3 是历史双列 PR 插图，背景与裁切影响阅读。不能把这些分数解释成整产品排名。

此包为实际 Linux Electron 截图、孤立合成 FakeModel 数据；即使几何和展开状态匹配，session 身份、侧栏历史和拍摄时刻仍可能不同，不是完全受控因果 A/B。无整体赢家、无均分、无强制评分变化。静态图不证明供应商保存、模型选择持久化、网络/隐私行为、安装、完整键盘序列、读屏覆盖、WCAG 或整产品质量；模型标签不构成后台服务身份认证。未见焦点不等于不支持焦点。
