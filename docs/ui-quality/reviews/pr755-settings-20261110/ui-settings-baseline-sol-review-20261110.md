## 综合限制与可检验后续

不做整体排名。候选设置截图具有较稳定的分区、边框/圆角与语义色系统；较一致的可见短板是小号次级文字、微小徽标、部分长值截断。列表密集态的重复亮色安装按钮增加注意竞争；空态则更从容。这些只是当前像素观察，不说明设计意图。

参考素材的像素尺寸、裁切、任务复杂度不同，Linear/Vercel 大字号局部不能直接证明全应用更佳。截图内光标/焦点只证明该控件在该帧有可见线索，不能证明 Tab 顺序或键盘完整性。未验证点击、保存、筛选、安装结果、网络、隐私、持久化、无障碍树或 WCAG 合规。

可证伪检查：同尺寸同内容重拍以比较字号/密度；测量次级文字和徽标对比度；以多个长模型名和多提供商检验截断/分组；录制完整键盘路径检查焦点与遮挡；滚动表单验证保存入口与工具条的实际可达性。以上尚未执行。
