### K/L 可观察差异
- K 的右侧两条消息正文更大、更深，易读性局部更好；L 的正文更小、更浅，信息卡整体也更短。
- 两者路径、生成标识及草稿标签不同，造成中央结果折行位置变化，不能将这些行数差异归因于布局改进。
- 主框架、栏宽、控件位置、色彩和导航基本相同。上述局部差异不足以跨越粗粒度评分档，因此各维度同分，不强行排名。

### 不确定性与可证伪下一步
- 参考图任务、缩放、裁切不同，不能把局部设置页面优势直接当作全应用优势。
- 用完全相同数据、窗口和字体比例重拍 K/L，可检验右侧字号/颜色差异是否稳定存在，并排除文案折行干扰。
- 测量文字与背景的实际对比度，可检验“次级文字较弱”的判断；当前未宣称 WCAG 合规或不合规。
- 录制 Tab 导航并捕获真实焦点态，检验焦点可见性和导航顺序；当前截图不能证明键盘完整性。
- 用同一条更长消息及更长路径复测，检验窄中栏是否出现不可读折行或溢出。
- 静态图不支持点击结果、隐私、网络行为、持久化或全产品质量结论。
