## 方法与边界

仅阅读指定包内 reviewer-brief.md 与五张原图，先参考图，再候选图；未读源码、其他评审、时间顺序或映射。0 不可用，1 明显短板，2 优缺点混合，3 扎实，4 出色；N/O 为未观察。各图独立评分，不计算总分或平均，不选赢家。

## 可证伪的后续检查

1. 候选小灰说明是最明确的可读性风险。以原生 100% 显示、实际字体与背景测对比，进行阅读任务并记录错读率；不能仅凭截图宣布通过或不通过 WCAG。
2. 检验最左截断的 Agent Infor… 在悬停或键盘到达后是否有完整名称；让用户辨认两个同名可见线程条目，记录是否选错。不假设缺失工具提示。
3. 分别用 Tab/Shift+Tab 遍历开关、输入、下拉、复选框和折叠项，检查焦点可见性、顺序与固定底栏遮挡。截图没有这项证据。
4. 滚到页面末端并放大到 200%，确认 Summary instruction 的全部内容、最后控件与 Apply 能到达，且固定栏不长期遮住正在操作的控件。当前裁切不构成功能缺失证据。
5. 用任务测试核验用户是否能从说明理解 agentic 开关与 Host compaction 的关系；本评审只观察到说明文本及层级，不验证其真实语义或执行后果。

## 不可见限制

未验证压缩算法、开关后果、保留规则、保存或持久化、输入校验、屏幕阅读器名称/语义、完整键盘行为、其他主题/窗口尺寸/数据状态或全产品质量。底栏“Your settings are up to date”和灰色 Apply 是可见状态文案，不是保存成功的独立证据。参考图同样没有证明其实际交互或现行线上产品状态。
