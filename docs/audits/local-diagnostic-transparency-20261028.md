## Non-concealment search matches

- `thread-title-ownership-transaction.ts` / thread-title-store safe abort machinery: listener isolation and ownership, not privacy masking.
- `renderer/src/plugin-ui-host.tsx` CSP unsafe-inline: sandbox markup policy, not diagnostic filtering.
- Build/capture/smoke scripts: CSP unsafe-inline, clipboardSanitizedWrite, and deliberate synthetic assertions; not production owner diagnostics.
- Shell/settings/panels translations: hiding sidebar/model/invitation, file list truncation, OS Privacy settings labels, and unknown hidden model reasoning timing are not error concealment. Remote public automation settings hiding program/env values is a remote visibility boundary.

## Evidence limits and next actions

`localErrorDetail` only serializes available exception data: bounded 8 levels, 256 field/object traversal units, 64Ki text characters, explicit cycle/accessor/truncation markers. It does not reconstruct errors already lost by an upstream generic catch. No unbounded object dump, HTTP request/config capture, or diagnostic text as recovery authority.

Native-host details use the existing owner diagnostics folder, 0600 file/0700 directory, bounded rotating records, with no automatic sharing. These permissions do not make publishing safe: external exports/issues still need cleaning/review. Auth-header API keys remain excluded from capture; no request headers are added by this work.

Non-adapter rows explicitly identified by this audit now have a bounded owner evidence path. Adapter transport/response evidence remains assigned separately and is not declared solved by this work. This remains keyword/call-path auditing rather than a proof of all possible exception paths.
