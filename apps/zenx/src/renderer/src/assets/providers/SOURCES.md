# Provider logo sources

These local assets identify known Provider presets in ZenX. The marks remain the
property of their respective owners and are used only for Provider identity.
Retrieved 2026-08-20.

- `openai.svg`: OpenAI Blossom from the official [OpenAI brand
  guidelines](https://openai.com/brand/) and the linked official
  [Blossom construction SVG](https://images.ctfassets.net/kftzwdyauwt9/3hUGLn3ypllZ0oa01qOYVq/28e8188e6f11b84c3e876569d492734f/Blossom_Light.svg).
  The local file isolates the first complete black Blossom path from that guide;
  its geometry is unchanged.
- `deepseek.svg`: DeepSeek whale symbol from the official
  [`deepseek-ai/DeepSeek-VL` logo](https://github.com/deepseek-ai/DeepSeek-VL/blob/681bffb4519856ad27cc17531aacde31ddf6f1a7/images/logo.svg)
  at repository commit `681bffb4519856ad27cc17531aacde31ddf6f1a7`
  (blob `425494404f7e63f4909667003097511217664579`). The local file
  isolates the standalone symbol path from the official wordmark SVG; its path
  data is unchanged.
- `qwen.svg`: copied from the official
  [`QwenLM/qwen-code` desktop logo](https://github.com/QwenLM/qwen-code/blob/313f19115014be37f133fafb4a74829468beb5ba/packages/desktop-shell/bootstrap/qwen-code-logo.svg)
  at repository commit `313f19115014be37f133fafb4a74829468beb5ba`
  (blob `bd100cf394ed156832734cb4b16b903949c6f232`). Its path and
  view box are unchanged.
- `siliconflow.svg`: copied from SiliconFlow's official homepage logo
  ([siliconflow.cn/logo-new.svg](https://siliconflow.cn/logo-new.svg)), retrieved
  2026-08-23. The asset is used unchanged; SiliconFlow retains all trademark
  rights.
- `dashscope.png`: official Alibaba Cloud Bailian/DashScope social image from
  the DashScope product page ([dashscope.aliyun.com](https://dashscope.aliyun.com)),
  retrieved 2026-08-23. It is used as a local identity asset; Alibaba retains
  all trademark rights. DashScope is intentionally not mapped to Qwen.
- `moonshot.ico`: official Moonshot/Kimi site favicon from
  [moonshot.cn](https://www.moonshot.cn/favicon.ico), retrieved 2026-08-23.
  It is used unchanged as the compact Moonshot/Kimi identity asset; Moonshot AI
  retains all trademark rights.
- `zhipu.svg`: copied from Zhipu AI's official homepage logo
  ([zhipuai.cn/logo.svg](https://www.zhipuai.cn/logo.svg)), retrieved 2026-08-23.
  The asset is used unchanged; Zhipu AI retains all trademark rights.

Do not substitute these Provider marks for the independent ZenX product logo.
