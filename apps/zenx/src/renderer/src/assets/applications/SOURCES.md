# Application identity artwork

The shared Icon registry embeds these unchanged 24×24 path geometries, uniformly scaled to its 16×16 canvas and rendered with currentColor. All icons ship locally; no runtime network or native application inspection is used. Labels remain the accessible action names.

- VS Code: https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/visualstudiocode.svg
- Cursor: https://github.com/simple-icons/simple-icons/blob/16.0.0/icons/cursor.svg
